二、体验诊断（痛点）

编号痛点影响典型场景
D1移动端无 hover，卡片悬浮展开失效手机用户无法查看公式/习题数手机打开知识点列表
D2函数可视化默认折叠，缺少引导用户可能不知道有可视化、不点开首次进入详情页
D3可视化多为静态/需点按钮，参数不能实时联动探究式学习体验弱调 μ/σ 看分布变化
D4公式实验室结果为演示占位，非真实计算可信度低，无法验证作业输入自定义数据
D5缺乏全局搜索与进度/收藏知识点多时难定位、无学习闭环复习某章节
D6主题切换入口深（设置面板），无快捷键切换成本高明暗环境切换
D7详情页内章节/知识点切换需返回首页连续学习被打断学完一节下一节
D8缺少即时反馈（复制成功、加载态、输入校验）操作无确认感，易误以为卡顿复制公式 / 计算

五、分阶段实施路线图

阶段一 · 基础体验（P0）
  • A1 全局搜索
  • B1 移动端点击展开
  • C2 可视化参数实时联动
  • D-1 真实计算引擎
  • F1 学习进度持久化
目标：核心场景在桌面与移动端均可用、可信。
阶段二 · 学习闭环（P1）
  • A2/A3 导航与收藏
  • B2/B4 状态与复制
  • C1 可视化引导
  • D-3/D-5 校验与复制
  • E1 Toast · F2 错题本
  • G1 移动导航 · H1 模块化
目标：形成「学—练—收藏—复习」闭环。
阶段三 · 精细打磨（P2）
  • B3/C3/C4 内容分段与联动
  • D-2/D-4 工具箱增强
  • E2/E3 动效与快捷键
  • F3 streak
  • G2/G3 无障碍 · H2 资源优化
目标：专业级交互质感与可访问性。
验收建议
  • 每阶段以「可点击原型 + 真实数据」验收
  • P0 须覆盖桌面 + 移动双端回归
  • 建立简单交互走查清单（10 项）

六、结语

当前版本已搭建起扎实的交互骨架，尤其在「悬浮卡片、可折叠可视化、多主题、工具箱 Tab」等细节上体现了良好的设计意识。下一步的重心应从「功能可用」转向「体验可信与闭环」——真实计算、移动端适配、学习进度是 P0 三件最值得优先投入的事；在闭环成型后，再以微交互与无障碍细节提升整体质感。

说明：本文档为建议性评审，具体落地顺序可结合开发资源与课程节点（如暑期交付计划）灵活调整。
